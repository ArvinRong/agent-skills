# 验收和交付

## 参数证据

固定字段不是都存在于 `V$DM_INI`。页/簇、字符集、大小写以系统函数核验；其他字段查询运行值、文件值和参数类型。`READ ONLY`可能是固化项，也可能是只能编辑文件后重启的普通项，不能仅凭这个标签断言全部不能修改。

`PARA_VALUE`、`FILE_VALUE`不同通常说明静态改动尚未生效或写入范围不同。SESSION项还核对管理会话值；应用现存连接需重连后测试。对于每项用户要求，建立一一对应的验收行，不以查询返回exit code=0代替检查SQL是否有错误。

可在已登录的会话使用只读文件 [../assets/verify.sql](../assets/verify.sql)。它读取版本、实例、固化值、配置范围、profile、用户/schema和权限摘要，不读取业务数据或密码散列。查询不存在/无权限字段时，查看视图结构并适配，不对数据库做DDL修复查询。

## 验收清单

| 检查 | 有效证据 |
| --- | --- |
| 软件组件/依赖 | `dmserver/dminit/disql`存在，`ldd`未缺库，确认过组件清单 |
| 专用用户/权限 | 进程用户、配置文件属主与权限、新登录ulimit和systemd有效限制 |
| 服务 | 精确服务名的active/enabled，启动日志就绪，无未处理错误 |
| 数据库状态 | SYSDBA认证成功，实例OPEN/NORMAL或确认模式 |
| 固化参数 | 系统函数+初始化日志实际值与清单一致 |
| SQL行为 | 经确认的只读常量查询；应用迁移要求另做应用回归 |
| 安全参数 | 全局复杂度、受影响用户profile及状态，审计0/1/2与确认一致 |
| 归档 | `ARCH_MODE=Y`、有效归档配置、目的目录/上限及实际文件，不只看ARCH_INI |
| 网络 | 实际监听、活动防火墙规则、永久规则、已授权来源节点TCP测试 |
| 容量 | 实际每个redo大小、数据/归档/审计/临时/备份所在卷容量及增长余量 |
| 持久化 | 必要且获授权的重启后重新登录和重查，不强制重启在用库 |

只读行为例子：

```sql
SELECT CASE WHEN 'abc'='ABC' THEN 1 ELSE 0 END AS CASE_EQUAL, 10/3 AS DIV_RESULT;
SELECT V FROM (SELECT CAST(NULL AS INTEGER) V UNION ALL SELECT 1) T ORDER BY V;
```

它们测试当前连接可观察行为，不能完全覆盖Oracle兼容或应用语义。不为参数验收擅自创建表、修改原业务数据或触发故意失败登录。

## 交付记录

用户要求保存文档时，沿用明确的长期目的地和格式；没有指定时可建议服务器家目录或团队运维文档目录。不要只放在隐藏 `.runtime` 中后称为长期交付。Windows链接使用完整路径和正斜杠，例如 `[部署记录](E:/operations/dameng-handover.md)`。

文档至少包括：

1. 采集时间、目标服务器和当前实际规格。
2. 介质路径/版本/许可到期，软件组件及许可证状态。
3. 每个目录的用途、挂载卷、权限和服务名/运维命令。
4. 地址/端口/实例/库名，管理账号和业务用户；密码默认不包含。
5. 用户要求与实际固化、兼容、安全、内存、日志/归档参数。
6. 防火墙来源名单及测试范围；未开通外部接入时明确标记。
7. schema和用户信息如有采集：状态/profile/默认表空间、对象数量、直接及角色权限、空间占用。已有账号的密码无法从字典取明文，不猜测业务口令。
8. 备份与恢复计划的实际状态，未做基线备份不能写“生产备份完成”。
9. 不支持参数、用户决定、未实施项和其他待办。

只有用户明确授权在该交付文件中包含密码时，敏感文件可包含用户提供的凭据；同一任务中已有的明确授权有效，不重复询问。服务器权限设为600且校验属主，本地文件依组织保管要求。不在默认打印/检验输出中回显口令，不上传敏感资料到可复用skill仓库。

保存后用文件元数据/摘要/非敏感章节核验。本地和服务器都保存时，两侧摘要一致才说已同步。最末简洁报告实际可连接状态及例外，不能只给安装命令执行过程。
